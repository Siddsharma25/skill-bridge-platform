# skill-bridge-platform

Job/skill-gap matching platform. Learning-focused polyglot microservices monorepo — see `docs/DECISIONS.md` for the full architecture and the reasoning behind every non-obvious choice before making structural changes.

## Stack

- **frontend/** — React 19 + Vite + TypeScript + Tailwind + shadcn/ui + TanStack Query + Zustand + React Hook Form + Zod + React Router.
- **backend/** — Go microservices (`auth`, `users`, `skills`, `jobs`, `api-gateway`), gRPC via proto-first `buf` codegen, GraphQL gateway via `gqlgen`, GORM + Supabase Postgres.
- **backend/notification-service/** — NestJS, consumes RabbitMQ only.
- **docker/**, **k8s/**, **jenkins/** — local infra/orchestration practice, not the production deploy path (Render + Vercel is).

## Commands

```
# frontend
cd frontend && npm run dev / npm run build / npm run lint

# backend (once scaffolded — see backend/CLAUDE.md)
cd backend && make gen        # regenerate gRPC/gqlgen stubs after editing a .proto or GraphQL schema
cd backend && make test
cd backend && make lint
```

## Conventions

- `backend/gen/` is generated by `buf generate` and **committed** — never hand-edit it, run `make gen` instead.
- Every Go service gets health/readiness endpoints, graceful shutdown, and `x-request-id` propagation from `internal/platform` — these aren't optional per-service boilerplate to skip.
- Each service/module has its own short README explaining what it does and why it's built that way — update it alongside the code, don't batch it at the end.
- Nested `frontend/CLAUDE.md` and `backend/CLAUDE.md` hold stack-specific conventions; this file stays high-level.

## Don't

- Don't add a database-per-service via multiple Supabase projects — one instance, schema-per-service, per-service Postgres roles (see `docs/DECISIONS.md`).
- Don't have jobs-service call users-service's database or a synchronous RPC for skill data — it consumes `user.skills.updated` off Kafka into its own snapshot table instead.
- Don't wire real email sending into notification-service — it logs/records only, by design.
